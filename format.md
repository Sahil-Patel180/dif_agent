# Diamond Report Format

This workbook contains two sheets:

1. **Summary**
2. **Details**

## 1. Summary

The **Summary** sheet provides a high-level view of vendor stock based on a selected date range.

### Date Filters

| Field | Description |
|---|---|
| From Date | Starting date for the report |
| To Date | Ending date for the report |

### Summary Columns

| Column | Field |
|---|---|
| A | Company |
| B | Location |
| C | Vendor stock # |
| D | Max discount |
| E | Report date |
| F | Key to symbol |

---

## 2. Details

The **Details** sheet contains complete information for each individual stock item.

### Detail Columns

| Column | Field |
|---|---|
| A | Location |
| B | Shape |
| C | Size |
| D | Color |
| E | Clarity |
| F | Cut |
| G | Polish |
| H | Symmetry |
| I | Fluorescence |
| J | Lab |
| K | %RAP |
| L | Depth |
| M | Table |
| N | Measurements |
| O | Ratio |
| P | Vendor stock # |
| Q | Key to symbols |
| R | Company |
| S | Report date |
| T | Report comment |
